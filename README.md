## Features

- **Accurate table extraction** — three modes: `Auto` (ruled → borderless fallback per page), `Ruled` (line-based), `Borderless` (text-alignment-based), powered by [pdfplumber](https://github.com/jsvine/pdfplumber)
- **Batch conversion** — drag & drop multiple PDFs, per-page progress bar, cancellable, one failure never blocks the queue
- **Page ranges** — convert only what you need, e.g. `1-5,8,11-13`
- **Sheet layouts** — merge all pages into one sheet, or one sheet per page
- **Encrypted PDFs** — per-file password prompt built into the UI
- **Smart fallbacks** — text extraction when no table is found; clear notice for scanned (image-only) PDFs
- **Polished Excel output** — styled header row, frozen top row, auto column widths (CJK-aware), thin borders
- **100% local & offline** — files never leave your machine; no account, no upload
- **CLI included** — scriptable conversion without the GUI

## Build from Source

Requires **Python 3.10+**.

**macOS**

```bash
git clone https://github.com/OWNER/pdf2excel.git
cd pdf2excel
bash build_mac.sh          # → dist/PDF2Excel.app
```

**Windows**

```bat
git clone https://github.com/OWNER/pdf2excel.git
cd pdf2excel
build_windows.bat          :: → dist\PDF2Excel.exe
```

Both scripts create a virtual environment, install dependencies, generate icons, and package with PyInstaller — no manual steps.

## Run without Packaging (Dev Mode)

```bash
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
python main.py
```

## CLI Usage

```bash
python main.py --cli input.pdf -o output.xlsx
python main.py --cli report.pdf --mode text --pages 1-5,8 --sheet pages
python main.py --cli secret.pdf --password 123456
```

| Option | Values | Default | Description |
|---|---|---|---|
| `-o, --output` | path | same name `.xlsx` | Output file |
| `--mode` | `auto` / `lines` / `text` | `auto` | Table extraction strategy |
| `--pages` | e.g. `1-5,8` | all | Page range |
| `--sheet` | `merge` / `pages` | `merge` | Worksheet layout |
| `--password` | string | — | Password for encrypted PDFs |

## How It Works

```
PDF ──▶ pdfplumber ──▶ table cells (ruled / text-aligned)
      ──▶ text fallback (no table found)
      ──▶ scanned-page notice (no text layer)
                          │
                          ▼
              openpyxl ──▶ styled .xlsx
```

The GUI is a native [pywebview](https://pywebview.flowrl.com/) window rendering a hand-crafted, dependency-free HTML/CSS/JS interface — Electron-grade polish at a fraction of the size.

```
└── build_windows.bat    # One-click Windows build → .exe
```
